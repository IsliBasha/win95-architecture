   ├─ Screensaver ← useInactivity 45s
   └─ BootSequence ← sessionStorage, once/tab
Four architectural layers
Context
WindowStackProvider owns global state: an ordered array (z-index = position in array) + three Sets/Maps for hidden, closed, maximized.
Components
Thin wrappers. Read context, render JSX. No game logic, geometry, or API calls inline.
lib/
Pure functions — no DOM access. Testable in isolation: computeResize, minesweeper, snake, bootChime.
hooks/
Behavioral reuse — useClock, useInactivity, useWindowPosition, useIconPosition, useInView.

Drag · Pointer Events API
// mouse events break when cursor exits element at speed
// Pointer Events route ALL events to capturing element

el.setPointerCapture(e.pointerId)

// store in ref — NOT state — avoids 60 re-renders/sec
const dragState = useRef({ startX, startY, ox, oy })
// only call setOffset() when DOM actually needs to move
Z-Index · Array as implicit ordering
// order[] = array of window IDs
// a window's z-index = its index in the array

function bringToFront(id) {
  return [...order.filter(x => x !== id), id]
} // last element on top. always 0..n, no overflow
HashRouter · Why not BrowserRouter
// BrowserRouter: /projects → server must serve index.html
// GitHub Pages has no rewrite rules → 404 on refresh

// HashRouter: /#/projects → server only ever sees /
// always serves index.html, browser handles fragment

// RouterSync (renderless): reads hash on mount → open window
// writes hash when window opens → every URL is deep-linkable
minimize vs close
'hidden' Map: window stays in DOM, display:none — taskbar button persists. 'closed' Set: removed from render tree entirely. Reopening gives a clean slate — authentic Win95 feel.
📄 lib/ — Pure Logic Pattern
_□✕
The rule: logic without DOM lives in lib/
// lib/resizeWindow.js — pure, testable, zero React
export function computeResize(edge, start, delta) {
  const w = Math.max(MIN_W, start.w + delta.x)
  const h = Math.max(MIN_H, start.h + delta.y)
  return { width: w, height: h }
} // unit-tested without mounting any component
// lib/minesweeper.js — board = 2D array of plain objects
createBoard() → Board    // empty grid, no mines yet
revealCell(b,r,c) → Board // plants mines on first call
flagCell(b,r,c) → Board  // returns new state, no mutation
Why this matters
"Keep logic that doesn't need the DOM out of components and into lib/" — Isli Basha
→ Faster tests — no component mount, no jsdom overhead, just data in → data out
→ Parallel development — Isli built the window shell while Sidrit wrote game logic independently, zero coupling
→ Easier to reason about — pure function: same input always gives same output, no hidden state
→ Portable — game logic usable outside React without changes

🎮 games — Safe First Click · Functional Updater
_□✕
Minesweeper · Safe First Click
// createBoard() — empty grid, no mines placed yet
function revealCell(board, r, c) {
  if (!board.minesPlanted) {
    // first click: plant mines, skip [r,c] + neighbors
    board = plantMines(board, r, c)
  }
  // flood-fill with iterative stack — not recursion
  // avoids RangeError on large open fields
  const stack = [[r, c]] // heap, no call-stack limit
  while (stack.length) { /* pop → check → push neighbors */ }
}
The safe-start guarantee is entirely internal to lib/. The caller never has to think about it.
Snake · Stale Closure & Direction
// turn() rejects if new dir is opposite of current
// prevents instant self-reversal death (feels unfair)

// Stale closure problem:
// setGame(tick(game)) — 'game' is always initial value
// because setInterval closes over it at creation time

// Fix: functional updater — React gives latest state
setGame(g => tick(g))
→ Logic written and unit-tested before any JSX was opened
→ Components are thin wrappers: mount → tick interval → keydown → render projection of lib state

useClock · Minute-aligned, no drift
// setInterval(tick, 60000) at 14:23:47
// → next fire: 14:24:47 (47 seconds past the minute — wrong)

// Fix: align to next minute boundary with a one-shot timeout
const msUntil = (60 - sec) * 1000 - ms
setTimeout(() => {
  tick()                          // immediate update
  setInterval(tick, 60_000)   // fires exactly at :00
}, msUntil)
useInactivity · Passive listeners
// 5 events: mousemove keydown pointerdown scroll touchstart
// all registered {passive:true} — browser can scroll freely
// on each event: clearTimeout + restart 45s timer
// on timeout: screensaver activates
BootSequence · Three phases
→ BIOS text output → memory check animation → Windows 95 splash
→ Plays once per tab via sessionStorage — not localStorage (new tab = new boot)
→ Skips entirely on prefers-reduced-motion — added proactively
bootChime · Web Audio API
// Audio file = network fetch, can arrive late, timing broken
// Web Audio: oscillator + gain envelope, synthesized instantly
// zero network dependency, zero latency, no binary assets
// synthetic sound fits the 8-bit aesthetic anyway
